ОБНОВЛЕНИЕ БОТА: ПОДДЕРЖКА КОРОТКИХ ССЫЛОК ЯНДЕКС МАРКЕТА

1. Останови бота в окне PowerShell или командной строки: Ctrl+C.
2. Открой папку проекта, где сейчас находятся bot.py и файл .env.
3. На всякий случай переименуй старый bot.py в bot_old.py.
4. Распакуй этот архив и скопируй новый bot.py в папку проекта.
5. Не удаляй и не заменяй свой .env: в нём хранится токен бота и настройки канала.
6. Открой терминал в папке проекта и запусти:
   py -m pip install -r requirements.txt
   py bot.py

ЧТО ИЗМЕНИЛОСЬ
- Бот пытается пройти по перенаправлениям коротких ссылок вида https://market.yandex.ru/cc/XXXX.
- После перехода пробует получить название из метаданных страницы и заголовка.
- Если название не найдено, проверяет известные названия по ID карточки.
- Последний запасной вариант — преобразование латинской части адреса в кириллицу.
- Если Яндекс Маркет не разрешает автоматический доступ или не раскрывает короткую ссылку, бот может попросить ввести название вручную.
- В публикации убрана фраза «Нашли классное предложение!», добавлен 🔥 перед названием и эмодзи перед ссылками на Telegram и Max.

ВАЖНО
Автоматическое получение названия зависит от ответа Яндекс Маркета и не гарантируется для каждой ссылки. После обновления отправь боту короткую ссылку и проверь предпросмотр до публикации.
Токен из .env никому не отправляй.


НАСТРОЙКА API ЯНДЕКС МАРКЕТА (необязательно)

1. Открой файл .env в Блокноте.
2. Добавь строки:
   YANDEX_MARKET_API_TOKEN=НОВЫЙ_ТОКЕН_API
   YANDEX_MARKET_CLID=ТВОЙ_CLID
3. Сохрани файл и перезапусти бота.

Токен указывай без слова OAuth. Не присылай токен другим людям и не вставляй его в bot.py.
CLID нужно взять в кабинете реферальной программы Яндекс Маркета. Значение 2310490 в примере документации не следует считать твоим CLID.

При обработке названия бот пробует API, затем обычную страницу товара и запасные способы. API-метод может не поддерживать отдельные типы ссылок; в таком случае бот продолжит работу без API.

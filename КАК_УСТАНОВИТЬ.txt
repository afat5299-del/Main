УСТАНОВКА TELEGRAM-БОТА

1. Установите Python 3.10 или новее с сайта python.org. При установке включите Add Python to PATH.
2. Распакуйте архив в отдельную папку.
3. Откройте эту папку в Проводнике. Создайте копию файла .env.example и назовите её .env.
4. Откройте .env в Блокноте и укажите BOT_TOKEN, полученный у @BotFather. Не отправляйте токен никому.
5. Чтобы бот публиковал посты в канал, добавьте в TARGET_CHANNEL имя канала, например @my_channel, и назначьте бота администратором с правом публикации. Если нужна только подготовка постов в личном чате, оставьте TARGET_CHANNEL пустым.
6. В адресной строке папки Проводника напишите cmd и нажмите Enter.
7. Выполните команды по очереди:
   py -m pip install -r requirements.txt
   py bot.py
8. Откройте бота в Telegram и отправьте /start.

Короткие ссылки раскрываются только для поиска названия. В публикации остаётся исходная ссылка, которую вы прислали, включая реферальные параметры. Если сайт не отдаёт название в структурированных данных или заголовке товара, бот попросит ввести его вручную.

# Telegram-бот для постов о товарах

## Возможности
- Принимает фото, ссылку и промокод в подписи к фото или отдельными сообщениями.
- Пытается извлечь название товара из обычного HTML страницы.
- Даёт вручную ввести название, если автоматическое извлечение не получилось.
- Добавляет ссылки на Telegram-канал и Max в каждый пост.
- Показывает предпросмотр и может публиковать в канал.

## 1. Установи Python
Установи Python 3.10 или новее с сайта https://www.python.org/downloads/
На Windows при установке отметь **Add Python to PATH**.

## 2. Создай бота и получи токен
1. Открой Telegram и найди официального бота `@BotFather`.
2. Отправь `/newbot`.
3. Следуй инструкциям и скопируй токен.
4. Не отправляй токен другим людям и не публикуй его в интернете.

## 3. Настрой файлы
Скопируй `.env.example` в файл с именем `.env`.
Открой `.env` в Блокноте и вставь токен:

```env
BOT_TOKEN=ВСТАВЬ_СЮДА_ТОКЕН_ОТ_BOTFATHER
TARGET_CHANNEL=
```

Чтобы бот мог публиковать посты в канал:
1. Добавь бота в свой Telegram-канал администратором.
2. Разреши ему публикацию сообщений.
3. В `.env` укажи username канала, например `TARGET_CHANNEL=@my_channel`.
   Если канал приватный, может понадобиться числовой ID вида `-100...`.
   Не используй ссылку-приглашение вместо ID канала.

Если оставить `TARGET_CHANNEL=` пустым, бот сможет подготовить пост и показать предпросмотр, но публикация в канал не будет работать.

## 4. Установи зависимости
Открой командную строку/терминал в папке проекта и выполни:

```bash
python -m pip install -r requirements.txt
```

На некоторых компьютерах вместо `python` нужно написать `py` (Windows) или `python3` (macOS/Linux).

## 5. Запусти бота
```bash
python bot.py
```

Оставь окно терминала открытым, пока бот нужен. Для остановки нажми `Ctrl+C`.
Для постоянной работы 24/7 нужен компьютер, который не выключается, или VPS/сервер.

## Как пользоваться
- `/start` — приветствие и инструкция.
- `/new` — новый черновик.
- `/cancel` — отменить текущий черновик.
- Отправь фото с подписью, содержащей ссылку и `Промокод: ABC123`, чтобы бот распознал всё в одном сообщении.
- Либо отправляй фото, ссылку и промокод по очереди.
- Если бот не смог получить название автоматически, отправь название отдельным сообщением.
- Нажми «Готово», чтобы закончить, даже если некоторых данных нет.

## Важные ограничения текущей версии
- Черновики хранятся в оперативной памяти; после перезапуска незавершённые черновики пропадут.
- Автоматическое извлечение названия с Яндекс Маркета не гарантируется: страница может быть динамической, недоступной или защищённой от автоматических запросов.
- Если в сообщении несколько URL, используется первая найденная ссылка.
- Для безопасности бот не должен использоваться для публикации чужих изображений/товарных материалов без соответствующих прав.

# Telegram + MAX: бот для подготовки товарных постов

## Что делает бот
- Черновик товара и все изменения по-прежнему выполняются в Telegram.
- Кнопка отправки публикует оригинальную версию в Telegram-канале `@ffffhhy1` (или другом канале, указанном в `TARGET_CHANNEL`) без изменения её подписей и ссылок.
- Затем отправляется отдельная версия в личный диалог MAX: это сообщение **от MAX-бота пользователю**, а не публикация в MAX-канале.
- Только в версии для MAX ссылки внизу поста меняются так:
  - «Подписаться на наш канал» ведёт на `https://max.ru/channel_skidochnayapromo`.
  - «Наш канал в Телеграм» ведёт на `https://t.me/+zOfQvQP-qcxmZjcy`.
- Если у товара есть фото, бот скачивает его из Telegram и загружает в MAX через API.
- Если отправка прошла только на одной платформе, бот сообщает об этом; повторная попытка не отправляет повторно уже успешно доставленную версию.

## Настройка
Открой `bot.py` и заполни блок «НАСТРОЙКИ» в начале файла:

1. `BOT_TOKEN` — токен Telegram-бота от @BotFather.
2. `TARGET_CHANNEL` — Telegram-канал. По умолчанию укажи `@ffffhhy1`.
3. `MAX_BOT_TOKEN` — токен MAX-бота из платформы разработчиков MAX.
4. `MAX_TARGET_USER_ID` — **числовой user_id твоего аккаунта MAX**, которому MAX-бот будет присылать сообщения. Это не ссылка на канал и не ID MAX-бота.

### Важно для личных сообщений MAX
- Сначала открой своего MAX-бота в приложении MAX и нажми **«Старт»**. Бот не может самовольно начать новый диалог с пользователем, который ещё не запускал его.
- Для отправки через API нужен числовой `user_id` получателя. Его можно получить через событие MAX API `message_created`/`bot_started` при подключённом получении обновлений; если ID пока неизвестен, не подставляй вместо него ссылку на профиль или канал.
- Если пользователь заблокировал MAX-бота или не запускал его, MAX может отклонить отправку.
- Telegram-бот и MAX-бот — разные боты; запуск Telegram-бота не заменяет запуск MAX-бота.

Добавь Telegram-бота администратором `@ffffhhy1` с правом публикации.

## Установка и запуск
Нужен Python 3.10 или новее:

```bash
python -m pip install -r requirements.txt
python bot.py
```

## Официальная документация MAX

- Загрузка изображений: https://dev.max.ru/docs-api/methods/POST/uploads
- Получение ID чата/канала: https://dev.max.ru/docs-api/use-cases/getting-chat-id

## Безопасность
Не передавай файл `bot.py`, если впишешь в него реальные токены. Токен даёт возможность управлять ботом; если он уже публиковался в переписке или где-либо ещё, перевыпусти его в соответствующей платформе. В архиве оставлены только заполнители.
